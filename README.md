# youtubecut

- **`mobile/`** — **CoverCut**, application de montage vidéo pour téléphone (PWA installable sur Android et iPhone) :
  découpe, réglages couleur, recadrage, bandes son avec synchro automatique, export H.264/HEVC matériel de 480p à 4K.
  Voir [`mobile/README.md`](mobile/README.md) pour l'installer sur ton téléphone.
- Racine (`app.py`, `gui.py`, `core/`…) — outil de bureau PySide6 pour télécharger une vidéo YouTube et en extraire des clips.
